# Функциональность обновления и дополнения датасетов

## Обзор

В плагин YOLO QGIS добавлена возможность обновления и дополнения существующих датасетов. Это позволяет пользователям:

- Обновлять метаданные существующих датасетов
- Добавлять новые классы в датасет
- Дополнять датасет новыми изображениями и аннотациями
- Создавать резервные копии датасетов
- Управлять несколькими датасетами
- **НОВОЕ**: Поддержка растровых данных для экспорта изображений
- **НОВОЕ**: Выбор типа задачи (detect/segment) при обновлении
- **НОВОЕ**: Валидация совместимости типов задач
- **НОВОЕ**: Настройки экспорта изображений (размеры, DPI, формат)
- **НОВОЕ**: Автоматическое извлечение новых классов из векторного слоя
- **НОВОЕ**: Интерактивный выбор классов для добавления
- **НОВОЕ**: Полоса прокрутки для удобной навигации по интерфейсу

## Новые компоненты

### 1. DatasetManager (`dataset_manager.py`)

Основной класс для управления датасетами. Поддерживает:
- Загрузку существующих датасетов (NDJSON и YOLO форматы)
- Обновление метаданных
- Добавление новых классов
- Дополнение датасета новыми данными
- Создание резервных копий

### 2. DatasetUpdateDialog (`dataset_update_dialog.py`)

Диалог для обновления существующих датасетов:
- Выбор датасета для обновления
- Обновление метаданных (название, описание, URL)
- Добавление новых классов
- Дополнение новыми данными из QGIS слоев
- Автоматическое создание резервных копий
- **НОВОЕ**: Выбор типа задачи (detect/segment)
- **НОВОЕ**: Выбор растрового слоя для экспорта изображений
- **НОВОЕ**: Настройки экспорта (размеры, DPI, формат)
- **НОВОЕ**: Валидация совместимости типов задач
- **НОВОЕ**: Автоматическое извлечение новых классов из векторного слоя
- **НОВОЕ**: Интерактивный список найденных новых классов
- **НОВОЕ**: Возможность выбора конкретных классов для добавления
- **НОВОЕ**: Полоса прокрутки для удобной навигации по интерфейсу

### 3. DatasetUtils (`dataset_utils.py`)

Утилиты для работы с датасетами:
- Валидация датасетов
- Получение информации о датасетах
- Создание и восстановление резервных копий
- Очистка временных файлов
- Экспорт информации о датасетах

### 4. DatasetManagerDialog (`dataset_manager_dialog.py`)

Диалог для управления несколькими датасетами:
- Поиск и сканирование датасетов в директориях
- Просмотр информации о датасетах
- Создание резервных копий
- Очистка датасетов
- Экспорт информации

## Использование

### Обновление существующего датасета

1. Откройте плагин YOLO QGIS
2. На вкладке "Dataset" нажмите кнопку "Обновить датасет"
3. Выберите директорию с существующим датасетом
4. Нажмите "Загрузить датасет"
5. Выберите операции для выполнения:
   - Обновить метаданные
   - Добавить новые классы
   - Добавить новые данные
6. Заполните необходимые поля
7. Нажмите "Обновить датасет"

### Управление датасетами

1. На вкладке "Dataset" нажмите кнопку "Управление датасетами"
2. Укажите директорию для поиска датасетов
3. Нажмите "Сканировать"
4. Выберите датасет в таблице
5. Используйте доступные действия:
   - Информация - просмотр подробной информации
   - Создать резервную копию
   - Очистить - удаление временных файлов
   - Экспорт информации - сохранение информации в JSON
   - Открыть - открытие директории в проводнике

## Поддерживаемые форматы

### NDJSON формат
- Файл `data.ndjson` с метаданными и аннотациями
- Папка `images/` с изображениями, разделенными по train/val/test

### YOLO формат
- Файл `dataset.yaml` с конфигурацией
- Папка `images/` с изображениями
- Папка `labels/` с аннотациями в формате YOLO

## Безопасность

- Автоматическое создание резервных копий перед изменениями
- Валидация входных данных
- Обработка ошибок с информативными сообщениями
- Возможность восстановления из резервных копий

## Ограничения

- Поддерживаются только NDJSON и YOLO форматы
- Новые данные добавляются с теми же параметрами изображений, что и существующий датасет
- При добавлении новых классов ID назначаются автоматически

## Примеры использования

### Добавление новых классов

**Автоматическое извлечение (рекомендуется):**
1. Выберите векторный слой с объектами
2. Укажите поле с классами
3. Система автоматически найдет новые классы
4. Выберите нужные классы из списка
5. Классы будут добавлены с ID, следующими за существующими

**Ручной ввод (резервный вариант):**
```python
# В поле "Ручной ввод": "car, truck, bus"
# Результат: классы будут добавлены с ID, следующими за существующими
```

### Обновление метаданных

```python
# Название: "Обновленный датасет дорог"
# Описание: "Датасет с дополнительными классами транспортных средств"
# URL: "https://example.com/dataset"
```

### Дополнение новыми данными

1. Выберите растровый слой для экспорта изображений
2. Выберите слой объектов в QGIS
3. Укажите поле с классами
4. Выберите тип задачи (detect для рамок, segment для полигонов)
5. Настройте параметры экспорта (размеры, DPI, формат)
6. Настройте разбивку train/val/test
7. Новые данные будут добавлены к существующему датасету

**Важно**: При выборе типа задачи, отличного от существующего в датасете, система предупредит о несовместимости.

## Технические детали

### Структура файлов

```
dataset_manager.py          # Основной класс управления
dataset_update_dialog.py    # Диалог обновления
dataset_utils.py           # Утилиты
dataset_manager_dialog.py  # Диалог управления
```

### Зависимости

- qgis.PyQt (QtWidgets, QtCore)
- qgis.core (QgsVectorLayer, QgsProject)
- Стандартные модули Python (os, json, shutil, datetime)

### Интеграция

Новые функции интегрированы в существующий интерфейс плагина через:
- Кнопку "Обновить датасет" на вкладке Dataset
- Кнопку "Управление датасетами" на вкладке Dataset
- Импорт новых модулей в `yolo_qgis_dialog.py`
