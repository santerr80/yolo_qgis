# 🚀 Руководство по использованию интерфейса тренировки YOLO

## 📋 Обзор

Интерфейс тренировки YOLO моделей был полностью интегрирован в основную вкладку "Train" плагина. Теперь вы можете обучать модели детекции и сегментации объектов прямо из QGIS с полным контролем над процессом.

## 🎯 Основные возможности

### ✅ Что реализовано:
- **Полноценный интерфейс тренировки** с тремя вкладками: Обучение, Валидация, Метрики и графики
- **Поддержка детекции и сегментации** объектов
- **Анализ датасетов** перед тренировкой
- **Управление конфигурациями** (сохранение/загрузка)
- **Отслеживание прогресса** в реальном времени
- **Валидация моделей** с детальными метриками
- **Просмотр истории экспериментов**
- **Визуализация метрик** обучения

## 🖥️ Интерфейс

### Вкладка "Обучение"

#### 1. Группа "Датасет"
- **Путь к датасету**: Выберите директорию с датасетом в формате YOLO
- **Тип задачи**: Выберите между "Детекция объектов" и "Сегментация объектов"
- **Анализировать датасет**: Кнопка для анализа структуры и качества датасета

#### 2. Группа "Модель"
- **Тип модели**: Выберите размер модели (n/s/m/l/x)
- **Устройство**: CPU или GPU (CUDA)
- **Предобученная модель**: Использовать ли предобученные веса

#### 3. Группа "Параметры обучения"
- **Количество эпох**: 1-1000 (по умолчанию 100)
- **Размер батча**: 1-128 (по умолчанию 16)
- **Размер изображения**: 320-1280 пикселей (по умолчанию 640)
- **Скорость обучения**: 0.0001-1.0 (по умолчанию 0.01)

#### 4. Группа "Аугментация"
- **Мозаика**: Вероятность применения мозаичной аугментации (0.0-1.0)
- **Mixup**: Вероятность применения mixup аугментации (0.0-1.0)
- **Copy-Paste**: Вероятность применения copy-paste аугментации (0.0-1.0)
- **Горизонтальное отражение**: Вероятность отражения (0.0-1.0)

#### 5. Группа "Выходные данные"
- **Имя проекта**: Название для проекта тренировки
- **Директория сохранения**: Где сохранить результаты

#### 6. Кнопки управления
- **Начать обучение**: Запускает процесс тренировки
- **Остановить обучение**: Прерывает текущую тренировку
- **Загрузить конфигурацию**: Загружает сохраненные настройки
- **Сохранить конфигурацию**: Сохраняет текущие настройки

#### 7. Группа "Прогресс обучения"
- **Прогресс-бар**: Показывает общий прогресс
- **Статус**: Текущее состояние тренировки
- **Лог**: Подробная информация о процессе

### Вкладка "Валидация"

#### 1. Группа "Модель для валидации"
- **Путь к модели**: Выберите файл модели (.pt)
- **Датасет для валидации**: Выберите датасет для тестирования

#### 2. Группа "Параметры валидации"
- **Порог уверенности**: Минимальная уверенность для детекций (0.01-1.0)
- **Порог IoU**: Порог для Non-Maximum Suppression (0.01-1.0)
- **Макс. детекций**: Максимальное количество детекций на изображение
- **Комплексная валидация**: Включить детальный анализ

#### 3. Кнопки управления
- **Начать валидацию**: Запускает валидацию модели
- **Сравнить модели**: Сравнивает несколько моделей
- **Экспорт результатов**: Сохраняет результаты в файл

#### 4. Группа "Результаты валидации"
- **Таблица метрик**: Отображает основные метрики
- **Лог валидации**: Подробная информация о процессе

### Вкладка "Метрики и графики"

#### 1. Группа "Эксперименты"
- **Список экспериментов**: Все проведенные эксперименты
- **Информация об эксперименте**: Детали выбранного эксперимента
- **Кнопки управления**: Обновить, Удалить, Экспорт

#### 2. Группа "Метрики обучения"
- **Таблица метрик**: Метрики по эпохам
- **Графики**: Визуализация кривых обучения
- **Кнопки**: Создать графики, Сохранить графики

## 🚀 Пошаговое руководство

### Шаг 1: Подготовка датасета
1. Убедитесь, что ваш датасет имеет правильную структуру YOLO:
   ```
   dataset/
   ├── dataset.yaml
   ├── images/
   │   ├── train/
   │   ├── val/
   │   └── test/
   └── labels/
       ├── train/
       ├── val/
       └── test/
   ```

2. Выберите путь к датасету в поле "Путь к датасету"

3. Нажмите "Анализировать датасет" для проверки структуры

### Шаг 2: Настройка параметров
1. Выберите тип задачи (детекция или сегментация)
2. Выберите подходящий размер модели
3. Настройте параметры обучения
4. При необходимости настройте аугментацию

### Шаг 3: Запуск тренировки
1. Укажите имя проекта и директорию сохранения
2. Нажмите "Начать обучение"
3. Следите за прогрессом в группе "Прогресс обучения"

### Шаг 4: Валидация модели
1. Перейдите на вкладку "Валидация"
2. Выберите обученную модель и тестовый датасет
3. Настройте параметры валидации
4. Нажмите "Начать валидацию"

### Шаг 5: Анализ результатов
1. Перейдите на вкладку "Метрики и графики"
2. Выберите эксперимент из списка
3. Просмотрите метрики и создайте графики

## 💡 Советы по использованию

### Выбор модели
- **YOLOv8n**: Быстрая, для быстрого прототипирования
- **YOLOv8s**: Сбалансированная, хорошее соотношение скорость/точность
- **YOLOv8m**: Средняя, для большинства задач
- **YOLOv8l**: Большая, для высокого качества
- **YOLOv8x**: Максимальная, для лучшего качества

### Параметры обучения
- **Эпохи**: Начните с 100, увеличьте при необходимости
- **Размер батча**: Зависит от GPU памяти (8-32)
- **Скорость обучения**: 0.01 для большинства случаев
- **Размер изображения**: 640 для большинства задач

### Аугментация
- **Мозаика**: 1.0 для детекции, 0.5-1.0 для сегментации
- **Copy-Paste**: 0.3 для сегментации, 0.0 для детекции
- **Отражение**: 0.5 для большинства случаев

## 🔧 Управление конфигурациями

### Сохранение конфигурации
1. Настройте все параметры
2. Нажмите "Сохранить конфигурацию"
3. Введите имя конфигурации

### Загрузка конфигурации
1. Нажмите "Загрузить конфигурацию"
2. Выберите сохраненную конфигурацию
3. Параметры автоматически применятся

## 📊 Анализ датасета

Функция анализа датасета показывает:
- Структуру датасета
- Количество изображений и аннотаций
- Распределение по классам
- Статистику по сплитам (train/val/test)
- Качество аннотаций

## 🎯 Валидация моделей

### Простая валидация
- Базовые метрики (mAP, precision, recall)
- Быстрое выполнение
- Подходит для быстрой проверки

### Комплексная валидация
- Детальный анализ по порогам
- Анализ ошибок
- Сравнение с другими моделями
- Экспорт результатов

## 📈 Метрики и визуализация

### Основные метрики
- **mAP50**: Mean Average Precision при IoU=0.5
- **mAP50-95**: Mean Average Precision при IoU=0.5-0.95
- **Precision**: Точность детекции
- **Recall**: Полнота детекции
- **Loss**: Функция потерь

### Графики
- Кривые обучения (loss, metrics)
- Сравнение экспериментов
- Анализ по эпохам

## ⚠️ Важные замечания

### Требования
- Python 3.8+
- PyTorch 1.9+
- Ultralytics 8.0+
- Достаточно GPU памяти для выбранного размера батча

### Ограничения
- Некоторые функции валидации требуют дополнительных зависимостей
- Графики генерируются только при наличии matplotlib
- Экспорт в некоторые форматы может быть недоступен

### Рекомендации
- Всегда анализируйте датасет перед тренировкой
- Сохраняйте конфигурации для повторного использования
- Мониторьте прогресс тренировки
- Валидируйте модели на тестовом датасете

## 🆘 Решение проблем

### Ошибки запуска тренировки
1. Проверьте путь к датасету
2. Убедитесь в правильности структуры датасета
3. Проверьте доступность GPU (если используется)
4. Уменьшите размер батча при нехватке памяти

### Проблемы с валидацией
1. Убедитесь, что модель обучена
2. Проверьте совместимость модели и датасета
3. Проверьте параметры валидации

### Ошибки интерфейса
1. Перезапустите плагин
2. Проверьте логи в консоли QGIS
3. Убедитесь в корректности установки зависимостей

## 📞 Поддержка

При возникновении проблем:
1. Проверьте логи в консоли QGIS
2. Убедитесь в корректности установки всех зависимостей
3. Проверьте структуру датасета
4. Обратитесь к документации модулей тренировки
