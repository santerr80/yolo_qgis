# Система обучения и валидации YOLO - Краткое описание

## 🎯 Цель проекта
Разработать комплексную систему для обучения и валидации YOLO моделей детекции и сегментации объектов в рамках QGIS плагина.

## 📁 Созданные файлы

### Основные модули
1. **`yolo_trainer.py`** (586 строк)
   - Базовый класс `YOLOTrainer` для обучения YOLO моделей
   - Класс `TrainingProgress` для отслеживания прогресса
   - Класс `TrainingThread` для выполнения обучения в отдельном потоке
   - Классы `ModelValidator` и `ModelPredictor` для валидации и предсказаний

2. **`yolo_detection_trainer.py`** (459 строк)
   - Класс `DetectionTrainer` для обучения моделей детекции
   - Класс `DetectionDatasetAnalyzer` для анализа датасетов детекции
   - Специализированные параметры аугментации для детекции
   - Методы экспорта моделей в различные форматы

3. **`yolo_segmentation_trainer.py`** (697 строк)
   - Класс `SegmentationTrainer` для обучения моделей сегментации
   - Класс `SegmentationDatasetAnalyzer` для анализа датасетов сегментации
   - Специализированные параметры для сегментации (mask_ratio, overlap_mask)
   - Методы создания и сохранения масок сегментации

4. **`yolo_validation.py`** (696 строк)
   - Класс `AdvancedValidator` для комплексной валидации
   - Класс `ModelComparator` для сравнения моделей
   - Анализ по порогам уверенности и IoU
   - Автоматическое создание графиков и отчетов

5. **`yolo_metrics_tracker.py`** (688 строк)
   - Класс `MetricsTracker` для отслеживания метрик
   - Класс `MetricsLogger` для логирования в различные форматы
   - Класс `MetricsDatabase` для работы с SQLite базой данных
   - Класс `MetricsVisualizer` для создания графиков

6. **`yolo_training_manager.py`** (Главный менеджер)
   - Класс `YOLOTrainingManager` - центральный менеджер системы
   - Класс `TrainingConfigManager` для управления конфигурациями
   - Интеграция всех компонентов системы
   - Сигналы для UI интеграции

### Документация и примеры
7. **`yolo_training_example.py`** - Подробные примеры использования
8. **`requirements_training.txt`** - Список зависимостей
9. **`README_training.md`** - Подробная документация
10. **`INTEGRATION_GUIDE.md`** - Руководство по интеграции
11. **`TRAINING_SYSTEM_SUMMARY.md`** - Данный файл

## 📊 Поддерживаемые метрики

### Детекция
- mAP50 (mean Average Precision при IoU=0.5)
- mAP50-95 (mean Average Precision при IoU=0.5-0.95)
- Precision (Точность)
- Recall (Полнота)
- F1-Score (Гармоническое среднее)

### Сегментация
- Все метрики детекции +
- IoU (Intersection over Union) для масок
- Dice Coefficient для масок
- Pixel Accuracy для масок
- Mean Accuracy по классам

## 📈 Примеры использования

### Быстрый старт
```python
from yolo_training_manager import YOLOTrainingManager

manager = YOLOTrainingManager()
experiment_id = manager.start_detection_training(
    dataset_path="path/to/dataset",
    model_type='yolov8n',
    epochs=100
)
```

### Комплексная валидация
```python
results = manager.validate_model(
    model_path="path/to/model.pt",
    dataset_path="path/to/dataset",
    comprehensive=True
)
```

### Сравнение моделей
```python
models = [
    {'name': 'Model_1', 'path': 'path/to/model1.pt'},
    {'name': 'Model_2', 'path': 'path/to/model2.pt'}
]
comparison = manager.compare_models(models, dataset_path)
```
