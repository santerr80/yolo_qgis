# Инструкции по тестированию функциональности обновления датасетов

## Подготовка к тестированию

### 1. Убедитесь, что у вас есть:
- QGIS 3.x с установленным плагином YOLO QGIS
- Существующий датасет (NDJSON или YOLO формат)
- Векторный слой с объектами для добавления в датасет

### 2. Структура тестового датасета:
```
test_dataset/
├── data.ndjson (для NDJSON формата)
├── dataset.yaml (для YOLO формата)
├── images/
│   ├── train/
│   ├── val/
│   └── test/
└── labels/ (для YOLO формата)
    ├── train/
    ├── val/
    └── test/
```

## Тестирование диалога обновления датасета

### Шаг 1: Открытие диалога
1. Запустите QGIS
2. Загрузите векторный слой с объектами
3. Откройте плагин YOLO QGIS
4. На вкладке "Dataset" нажмите кнопку "Update dataset"

**Ожидаемый результат:** Диалог должен открыться без ошибок

### Шаг 2: Загрузка датасета
1. В диалоге нажмите "Обзор..." рядом с полем "Путь к датасету"
2. Выберите директорию с существующим датасетом
3. Нажмите "Загрузить датасет"

**Ожидаемый результат:** 
- В текстовом поле должна появиться информация о датасете
- Поля метаданных должны заполниться автоматически
- Появится сообщение "Датасет успешно загружен"

### Шаг 3: Тестирование выбора слоев
1. Убедитесь, что в QGIS загружен векторный слой
2. В разделе "Новые данные" проверьте выпадающий список "Слой объектов"
3. Выберите слой из списка
4. Проверьте выпадающий список "Поле классов"

**Ожидаемый результат:**
- Список слоев должен содержать все векторные слои из проекта
- При выборе слоя список полей должен обновиться автоматически
- Список полей должен содержать все поля выбранного слоя

### Шаг 4: Тестирование обновления метаданных
1. Установите флажок "Обновить метаданные"
2. Измените значения в полях "Название", "Описание", "URL"
3. Нажмите "Обновить датасет"

**Ожидаемый результат:** Метаданные должны обновиться в файле датасета

### Шаг 5: Тестирование добавления классов
1. Установите флажок "Добавить новые классы"
2. В поле "Новые классы" введите: "car, truck, bus"
3. Нажмите "Обновить датасет"

**Ожидаемый результат:** Новые классы должны быть добавлены в датасет

### Шаг 6: Тестирование добавления данных
1. Установите флажок "Добавить новые данные"
2. Выберите слой объектов и поле классов
3. Настройте разбивку train/val/test
4. Установите флажок "Создать резервную копию"
5. Нажмите "Обновить датасет"

**Ожидаемый результат:** 
- Должна создаться резервная копия
- Новые данные должны быть добавлены в датасет
- Прогресс-бар должен показывать ход выполнения

## Тестирование диалога управления датасетами

### Шаг 1: Открытие диалога
1. На вкладке "Dataset" нажмите кнопку "Dataset management"

**Ожидаемый результат:** Диалог должен открыться без ошибок

### Шаг 2: Сканирование датасетов
1. В поле "Директория поиска" укажите папку с датасетами
2. Нажмите "Сканировать"

**Ожидаемый результат:** 
- В таблице должны появиться найденные датасеты
- Должно появиться сообщение с количеством найденных датасетов

### Шаг 3: Просмотр информации
1. Выберите датасет в таблице
2. Нажмите "Информация"

**Ожидаемый результат:** Должно открыться окно с подробной информацией о датасете

### Шаг 4: Создание резервной копии
1. Выберите датасет в таблице
2. Нажмите "Создать резервную копию"
3. Выберите директорию для сохранения

**Ожидаемый результат:** Должна создаться резервная копия датасета

## Возможные проблемы и решения

### Проблема: "Не найден поддерживаемый датасет"
**Решение:** Убедитесь, что в директории есть файл `data.ndjson` или `dataset.yaml`

### Проблема: "Выберите слой объектов"
**Решение:** Загрузите векторный слой в QGIS перед открытием диалога

### Проблема: "Выберите поле классов"
**Решение:** Убедитесь, что выбранный слой содержит поля с данными

### Проблема: Ошибки при добавлении данных
**Решение:** Проверьте, что слой содержит объекты в области видимости карты

## Проверка результатов

После успешного обновления датасета проверьте:
1. Резервная копия создана
2. Метаданные обновлены
3. Новые классы добавлены
4. Новые изображения и аннотации добавлены
5. Структура датасета сохранена
