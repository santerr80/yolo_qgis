## Новые возможности

1. **Растровые данные**: Теперь можно использовать растровые слои для экспорта изображений при обновлении датасета
2. **Тип задачи**: Поддержка выбора между detect (рамки) и segment (полигоны)
3. **Валидация**: Проверка совместимости типов задач между существующим и новым датасетом
4. **Настройки экспорта**: Гибкие настройки размеров, DPI и формата изображений
5. **Улучшенные метаданные**: Корректное объединение и обновление метаданных
6. **Автоматическое извлечение классов**: Новые классы автоматически извлекаются из поля классов векторного слоя
7. **Интерактивный выбор**: Возможность выбрать конкретные классы для добавления из найденных
8. **Умное сравнение**: Система автоматически сравнивает новые классы с существующими в датасете
9. **Удобная навигация**: Полоса прокрутки позволяет легко перемещаться по всем элементам интерфейса
