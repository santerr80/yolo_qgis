# Совместимость с numpy v1 - Инструкция

## Обзор

Все зависимости плагина YOLO QGIS теперь настроены для работы с numpy версии 1.x для обеспечения максимальной совместимости с QGIS.

## Что было сделано

### 1. Обновлен файл requirements.txt
- Ограничены версии всех зависимостей для совместимости с numpy v1
- Добавлены комментарии о совместимости
- Указаны конкретные диапазоны версий

### 2. Добавлены проверки совместимости в код
- В файлах `yolo_segmentation_trainer.py`, `yolo_validation.py`, `yolo_metrics_tracker.py`
- Автоматическая проверка версии numpy при импорте
- Предупреждения о несовместимых версиях

### 3. Создана утилита проверки совместимости
- Файл `compatibility_checker.py`
- Полная проверка всех зависимостей
- Детальный отчет о совместимости

## Использование

### Установка зависимостей
```bash
pip install -r requirements.txt
```

### Проверка совместимости
```bash
python compatibility_checker.py
```

### Проверка в коде
```python
import numpy as np
# Автоматически выводится предупреждение если numpy >= 2.0.0
```

## Ключевые ограничения версий

- `numpy>=1.21.0,<2.0.0` - основная зависимость
- `pandas>=1.3.0,<2.0.0` - обработка данных
- `matplotlib>=3.4.0,<4.0.0` - визуализация
- `opencv-python>=4.5.0,<5.0.0` - работа с изображениями
- `scikit-learn>=1.0.0,<2.0.0` - машинное обучение
- `scipy>=1.7.0,<2.0.0` - научные вычисления

## Преимущества

1. **Стабильность**: Гарантированная совместимость с QGIS
2. **Предсказуемость**: Известные версии всех зависимостей
3. **Отладка**: Автоматические предупреждения о проблемах
4. **Мониторинг**: Утилита для проверки состояния системы

## Устранение проблем

Если возникают проблемы с совместимостью:

1. Запустите `python compatibility_checker.py`
2. Проверьте отчет на наличие проблем
3. Переустановите несовместимые пакеты:
   ```bash
   pip install --force-reinstall 'numpy>=1.21.0,<2.0.0'
   ```
4. Используйте виртуальное окружение для изоляции

## Поддержка

При возникновении проблем с совместимостью:
- Проверьте версии всех зависимостей
- Убедитесь, что используется numpy v1.x
- Запустите утилиту проверки совместимости
