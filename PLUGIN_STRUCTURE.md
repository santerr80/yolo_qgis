## 🔄 Потоки данных

### 1. Создание датасета
```
Raster Layer + Vector Layer
         │
         ▼
   [Grid Creator] ──► Создание сетки
         │
         ▼
  [Intersection] ──► Нахождение пересечений
         │
         ▼
  [Map Exporter] ──► Экспорт изображений
         │
         ▼
[Dataset Formatter] ──► Форматирование в YOLO
         │
         ▼
     YOLO Dataset
```

### 2. Обучение модели
```
Dataset
   │
   ▼
[Dataset Manager] ──► Загрузка/управление
   │
   ▼
[Training Manager] ──► Управление процессом
   │
   ├──► [Detection Trainer] ──► Обучение детекции
   │
   └──► [Segmentation Trainer] ──► Обучение сегментации
         │
         ▼
[Metrics Tracker] ──► Отслеживание метрик
         │
         ▼
   Trained Model
```

### 3. Валидация модели
```
Trained Model + Test Dataset
         │
         ▼
[Advanced Validator] ──► Комплексная валидация
         │
         ├──► Анализ порогов уверенности
         ├──► Анализ порогов IoU
         ├──► Анализ по классам
         └──► Анализ ошибок
         │
         ▼
[Model Comparator] ──► Сравнение моделей
         │
         ▼
   Validation Results
```

## 📦 Основные классы и модули

### 🎯 Главный модуль плагина

#### `YoloQgis` (yolo_qgis.py)
- **Роль**: Главный класс плагина, точка входа
- **Ответственность**: 
  - Инициализация интерфейса QGIS
  - Управление жизненным циклом плагина
  - Создание и отображение диалогов

### 🖼️ Интерфейс пользователя

#### `YoloQgisDialog` (yolo_qgis_dialog.py)
- **Роль**: Главный диалог плагина
- **Функциональность**:
  - Создание датасетов YOLO из растровых и векторных слоев
  - Управление параметрами сетки и экспорта
  - Запуск обучения моделей
  - Управление датасетами

### 📊 Работа с данными

#### `DatasetManager` (dataset_manager.py)
- **Роль**: Управление датасетами
- **Функции**: Создание, загрузка, обновление датасетов

#### `dataset_formatter.py` / `dataset_formatter_yolo.py`
- **Роль**: Форматирование данных в формат YOLO
- **Функции**: Конвертация аннотаций, создание YAML конфигураций

### 🗺️ Геопространственные операции

#### `GridCreator` (grid_creator.py)
- **Роль**: Создание сетки для разбиения растровых слоев
- **Функции**: Генерация регулярной сетки для выборки данных

#### `Intersection` (intersection.py)
- **Роль**: Операции пересечения геометрий
- **Функции**: Нахождение пересечений объектов с ячейками сетки

#### `MapExporter` (map_exporter.py)
- **Роль**: Экспорт карт в изображения
- **Функции**: Сохранение участков карт в форматы изображений

### 🎓 Обучение YOLO

#### `YOLOTrainer` (yolo_trainer.py)
- **Роль**: Базовый класс для обучения YOLO моделей
- **Классы**:
  - `TrainingProgress` - отслеживание прогресса
  - `TrainingThread` - обучение в отдельном потоке
  - `ModelValidator` - валидация моделей
  - `ModelPredictor` - предсказания моделей

#### `DetectionTrainer` (yolo_detection_trainer.py)
- **Роль**: Обучение моделей детекции объектов
- **Наследуется от**: `YOLOTrainer`
- **Специализация**: Параметры и методы для детекции

#### `SegmentationTrainer` (yolo_segmentation_trainer.py)
- **Роль**: Обучение моделей сегментации объектов
- **Наследуется от**: `YOLOTrainer`
- **Специализация**: Параметры и методы для сегментации (маски)

#### `YOLOTrainingManager` (yolo_training_manager.py)
- **Роль**: Главный менеджер системы обучения
- **Функции**: 
  - Координация всех компонентов обучения
  - Управление экспериментами
  - Интеграция с UI

### ✅ Валидация и анализ

#### `AdvancedValidator` (yolo_validation.py)
- **Роль**: Расширенная валидация моделей
- **Классы**:
  - `ValidationResults` - хранение результатов валидации
  - `AdvancedValidator` - комплексная валидация
  - `ModelComparator` - сравнение моделей
- **Функции**:
  - Анализ порогов уверенности
  - Анализ порогов IoU
  - Анализ производительности по классам
  - Анализ ошибок

#### `MetricsTracker` (yolo_metrics_tracker.py)
- **Роль**: Отслеживание метрик обучения
- **Классы**:
  - `MetricsDatabase` - база данных метрик
  - `MetricsTracker` - отслеживание метрик
  - `MetricsVisualizer` - визуализация метрик

## 🔌 Точки интеграции

### QGIS API
- `QgsInterface` - интерфейс QGIS
- `QgsMapLayer` - работа со слоями
- `QgsVectorLayer` / `QgsRasterLayer` - векторные/растровые слои
- `QgsProject` - проект QGIS
- `QgsGeometry` - геометрические операции

### Qt/PyQt
- `QDialog` - диалоговые окна
- `QWidget` - виджеты интерфейса
- `QThread` - многопоточность
- `QSignal` / `QSlot` - сигналы и слоты

### YOLO/Ultralytics
- `ultralytics.YOLO` - основной класс YOLO
- Модели: YOLOv8n/s/m/l/x (detection/segmentation)
- Формат датасета: YOLO (images + labels + dataset.yaml)

## 🔄 Жизненный цикл плагина

```
1. QGIS загружает плагин
   └──► __init__.py::classFactory()
        └──► yolo_qgis.py::YoloQgis.__init__()

2. Инициализация интерфейса
   └──► YoloQgis.initGui()
        └──► Добавление меню и кнопки

3. Пользователь запускает плагин
   └──► YoloQgis.run()
        └──► YoloQgisDialog.show()

4. Пользователь работает с диалогом
   └──► YoloQgisDialog методы

5. Выгрузка плагина
   └──► YoloQgis.unload()
        └──► Удаление из меню и тулбара
```
